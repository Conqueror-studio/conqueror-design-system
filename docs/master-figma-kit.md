# Master Figma Kit Specification

Create one Figma file named **Conqueror Design System** with these pages: Cover, Philosophy, Foundations, Variables, Typography, Grid, Icons, Components, Editorial Modules, Patterns, Templates, Motion, Assets, Playground, Archive.

## Mandatory variables

Use primitive → semantic → component variables. No local hard-coded color, spacing, or type values in final components. Publish desktop, tablet (1024), and mobile (390) states.

## Foundations

- Canvas: Ivory `#F6F3EE`; ink `#111111`; blue `#2046F2` used only for active links, small details, lines, and primary action.
- Display type: Cormorant Garamond. UI/body: Inter. Confirm commercial licensing and web delivery before production.
- Desktop grid: 1440 frame, 80 side margins, 12 columns, 24 gutter, 1280 container. Mobile: 390 frame, 20 side padding, 4 columns.
- Use an 8-point spacing scale. Prefer square or subtle-radius editorial surfaces; no default soft SaaS cards.

## Components

Navigation, buttons, labels/museum tags, project card, journal card, service/craft list, quote, timeline, form controls, CTA, footer, and editorial modules: Pull Quote, Renaissance Caption, Museum Label, Section Number, Manuscript Divider, Timeline Marker, Signature Block, Curator Note, Cabinet Index.

Each component needs default, hover, focus, disabled/empty where applicable, and responsive behavior. All use Auto Layout and component properties.
